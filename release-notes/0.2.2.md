desertant 0.2.2 follows desert-ant-core 3.5.0.

- `da tongue` runs again. 0.2.1 left Tongue's weights out of the release and crashed with "unable to find bundle named DesertAnt_Tongue".
- If you installed with mise, run `mise use -g "ubi:Desert-Ant-Labs/desert-ant-cli[extract_all=true]"` once. The old line installed only the binary, so Tongue and Title could not find their files.

Install or update with `da update`, `brew upgrade desertant`, or `mise upgrade`.
