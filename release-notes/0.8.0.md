desertant 0.8.0 follows desert-ant-core 6.0.0.

- You can now set an API key for production use. You don't need a key for local experimentation.
- To save your key, run `da auth login`. In CI or a pipeline, set `DAL_API_KEY` instead.
- `da auth status` shows whether an API key is set, and `da doctor` shows the same.

Install or update with `da update`, `brew upgrade desertant`, or `mise upgrade`.
