desertant 0.3.0 follows desert-ant-core 4.0.0.

- To label who said what in a recording, run `da who talk.mp4`. To transcribe and label in one go, run `da voz talk.mp4 --speakers --names "Anna,Ben"`. The SRT, VTT, and text files carry the names.
- To find photos in a folder, run `da eye photos/ --has beach --not blurry`. `--duplicates` groups near-duplicates with the keeper first, `--best` picks one photo, `--sort aesthetic` ranks them, and `--crop 1:1` writes a crop. Eye is in closed beta, so set `HF_TOKEN` to a Hugging Face token with access to desert-ant-labs/eye.
- To pick a video's thumbnail, run `da eye launch.mp4 --thumbnail`. `--has people` lists the stretches where people are in frame.
- desertant runs on Linux, x86_64 and arm64, with glibc 2.35 or later. The install script works there too. ffmpeg reads compressed audio, video, and images, and libheif reads HEIC.
- `da voz` transcribes on Linux.
- `da ear` names the spoken language from 102 languages, up from 99.

Install or update with `da update`, `brew upgrade desertant`, or `mise upgrade`.
