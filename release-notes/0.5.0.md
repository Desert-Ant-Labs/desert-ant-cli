desertant 0.5.0 follows desert-ant-core 4.1.0.

- To run several models on a file in one command, run a flow: `da flow run podcast-clips episode.mp4` cleans up the sound, transcribes it, and cuts captioned clips. `da flow templates` lists the nine flows that ship, and `da docs flows` explains how to write your own.
- `da clips --captions burn` draws the captions into each clip, cut short for a phone screen. `--caption-style`, `--caption-position`, `--caption-align`, `--caption-font`, `--caption-size`, `--caption-weight`, and `--caption-color` set the look, and a clip looks the same on macOS and Linux.
- `da clips --captions srt` writes an `.srt` beside each clip.
- `da schema --json` lists every flow step, with its inputs, outputs, and settings.
- On Linux without ffmpeg, `da clips` says it needs ffmpeg before it transcribes, instead of after.

Install or update with `da update`, `brew upgrade desertant`, or `mise upgrade`.
