desertant 0.4.0 follows desert-ant-core 4.1.0.

- `da clips` runs on Linux. Voz transcribes the recording, Clips picks the moments, and ffmpeg cuts the clips.
- On macOS 27, `da uhm` runs on Core AI, with new weights, v1.2.0.
- On an Intel Mac, the install script says that desertant needs Apple silicon. In a Rosetta shell on Apple silicon, it installs the Apple silicon build.

Install or update with `da update`, `brew upgrade desertant`, or `mise upgrade`.
