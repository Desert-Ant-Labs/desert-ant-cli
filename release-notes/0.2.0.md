desertant 0.2.0 follows desert-ant-core 3.4.0 and adds Moderator and Tongue.

- Check a photo for nudity or sexual content with `da moderator photo.jpg`. Moderator runs on Apple silicon.
- Detect the language of a short text with `da tongue "<text>"`. Tongue needs three words and knows 84 languages.
- Transcribe every recording in a folder by passing the folder: `da voz interviews/`. Every command that reads files takes a folder or several paths, and `--recursive` includes the folders inside. The model loads once for the whole folder.
- With several files, `--json` prints one array with a result per file, in the order they ran. If a file fails, the CLI reports it on stderr and keeps going. One file still prints a single result, so scripts that parse it keep working.
- See where the CLI installs and caches its files, and how `da update` works for each install method, with `da docs files`.

Install or update with `da update`, `brew upgrade desertant`, or `mise upgrade`.
